# Экспедиции IT Start

Интерактивные рабочие листы Креайтивики. Открывайте отдельные папки module-N или общую карту.

В каждой экспедиции четыре станции по урокам модуля: понятия, оригинальные скриншоты, задача с пояснением, проверка своего проекта и ссылки на программу. Финальное испытание содержит восемь вопросов разных типов. Перетаскивание дополнено управлением нажатиями и кнопками; прогресс сохраняется локально отдельно для каждого модуля. Журнал можно скачать и распечатать.

Источники изображений и учебных тем указаны в sources.json каждой экспедиции. Личные заметки и ответы не отправляются на сервер. Существующая игровая мастерская в корне репозитория сохранена.
